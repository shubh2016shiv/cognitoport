ETL Data Validation Authoring with Multi Agent System

Healthcare ETL validation authoring · fixed-topology multi-agent system

From ETL validation descriptions
to executable PySpark scripts.

This system takes one data-validation requirement (a target table, a rule name, a sentence of plain English) and turns it into a deployable PySpark script for a healthcare ETL pipeline. A Planner resolves intent, an Executor implements the approved specification, and a Critique ensemble diagnoses and repairs the result. The sequence is fixed, every handoff is validated, and self-correction is the only loop allowed to run.
